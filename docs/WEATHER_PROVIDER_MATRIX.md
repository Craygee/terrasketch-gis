## Coverage rules

- NWS alerts are `observed/issued` official products, not LandDraft predictions.
- Model precipitation is never labeled radar. Where radar coverage is unavailable, the UI reports
  `RADAR UNAVAILABLE` and may separately offer a labeled model/satellite product.
- Without a user-connected Xweather account, the lightning layer is NOAA strike-density, not individual strikes.
  With Xweather connected it displays aggregated cloud-to-ground and intracloud flashes from the
  latest provider window. Development fixtures must carry `DEV DATA` and are rejected outside
  development/test channels.
- Source, issued/observed time, valid time, received time, age, quality, and provider identity travel
  with every normalized object.

## Vetted failover order

| Product               | Preferred                             | Automatic equivalent fallback                                    | Deliberate non-substitution                                                     |
| --------------------- | ------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| U.S. current/forecast | NWS point API                         | MET Norway model forecast if observation/forecast is missing     | A model result is labeled `MODEL`, never `OBSERVED`                             |
| CONUS radar           | NOAA/NWS MRMS composite reflectivity  | NWS base-reflectivity WMS, then user-connected Xweather global radar | Xweather's satellite-derived coverage is labeled `ESTIMATED`                 |
| Global radar          | User-connected Xweather global radar  | None                                                             | No satellite/model layer is silently relabeled radar                            |
| U.S. site radar       | Nearest official NEXRAD RIDGE II site | None; a failed site/catalog is reported                          | Base velocity is not called storm-relative velocity                             |
| Satellite             | User-connected Xweather imagery       | nowCOAST GOES/global imagery when Xweather is unavailable        | Forecast clouds are not called satellite imagery                                |
| Cloud-top temperature | NASA MODIS Terra/Aqua                 | None                                                             | Infrared brightness imagery is not relabeled as a sampled cloud-top temperature |
| Lightning             | User-connected Xweather flash imagery | nowCOAST regional lightning-density grid                         | Density cells are not called individual strikes                                 |
| Aviation stations     | Aviation Weather Center METAR         | None                                                             | Model conditions are not called station observations                            |

Provider failure is surfaced in the Weather source-health panel. LandDraft only switches to a
pre-reviewed equivalent adapter; it does not scrape arbitrary web search results into a live
operational map.

## Potential costs

- NOAA/NWS data is public, but reliable ingestion still consumes worker CPU, cache/object storage,
  bandwidth, monitoring, and engineering support.
- Raw NEXRAD/GOES processing can require significant compute and object storage; use immutable frame
  caching and spatial/temporal tiling rather than client-side bulk downloads.
- Global commercial weather, lightning, low-latency radar, road closures, push/SMS, offline packs,
  and historical archives may carry usage or redistribution fees.
- Xweather raster requests are counted per 256×256 tile per layer. Interactive viewports and
  animation can therefore consume many accesses; LandDraft keeps NOAA primary for U.S. radar,
  requests only active/visible products and begins high-multiplier air-quality/lightning products
  with one current frame. Each catalog row exposes its 1×, 5× or 10× access multiplier before use.
- Open-Meteo's free API is evaluation/non-commercial; production commercial use requires a suitable
  commercial agreement or self-hosted infrastructure plus attribution compliance.
